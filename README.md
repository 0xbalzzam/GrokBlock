# GrokBlock

Browser voxel defense game. Created by [@0xbalzzam](https://x.com/0xbalzzam).

Harvest wheat, sell it, buy swords and potions, chop trees, and patch your houses. Every night you have to kill 15 zombies. Every 5th night the boss is Elon. Host a room to play with friends: hits knock players down and take half their coins.

Play: open the GitHub Pages link after you enable Pages.

## Controls

- WASD move, mouse look, Space jump
- Left click hit, break, harvest
- F or right click place
- 1-6 hotbar, I inventory
- E sell wheat, Z/X/C blacksmith, H/J/U potions, V/B/G drink
- N skip to night
- Share on X posts how many nights you cleared

## Multiplayer

Host room, copy the code, send it with Share on X. Friends open the same site and paste the code into Join. The host tab has to stay open.
